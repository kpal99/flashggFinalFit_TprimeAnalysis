# Converting root files to workspace

- Run [tree2ws_.sh](./trees2ws_.sh) for converting singal samples
- Output of `tree2ws_.sh -h`:
```sh
trees2ws.sh [-n] [-d inputDir] [-y year] [-t] [-h]
  -n: dry run, do not run the script
  -d: input directory
  -y: year
  -t: test, run for single mass, decay width
  -h: print this message and exit
```
