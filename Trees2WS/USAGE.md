# Converting root files to workspace

- Run [tree2ws_all.sh](./trees2ws_all.sh) for converting signal samples
- Output of `tree2ws_all.sh -h`:
```sh
trees2ws_all.sh [-n] [-d inputDir] [-y year] [-t] [-h]
  -n: dry run, do not run the script
  -d: input directory
  -y: year
  -t: test, run for single mass, decay width
  -h: print this message and exit
```
